# BMW i7 M70 xDrive — Interactive 3D Digital Engineering Experience

A world-class, premium, fully responsive 3D interactive landing page for the **BMW i7 M70 xDrive**, built with React, TypeScript, Three.js, GSAP ScrollTrigger, Lenis smooth scrolling, and frame-accurate scroll-scrubbing.

---

## ✨ Features

- **Full-Screen Hero**: Cinematic dark studio opening featuring the assembled BMW i7 M70 xDrive with dynamic spotlight highlights and animated technical telemetry.
- **Scroll-Driven Disassembly**: Synchronized scroll-scrubbing deconstructing the vehicle across 188 1080p frames—separating the carbon hood, crystal lighting, frameless doors, Sky Lounge canopy, and dual eDrive motors down to the structural battery pack.
- **Exploded View Engineering**: Interactive blueprint hotspots with animated radar pulses, component selectors, and real-world verified BMW engineering benchmarks.
- **Power & Precision Performance**: Dynamic drive mode selector (M Sport Boost, Personal, Max Range), animated acceleration metrics, and dual eDrive telemetry (650 hp, 1,100 Nm torque, 0–100 km/h in 3.7s).
- **Design & Craftsmanship**: Edge-to-edge showcase highlighting the illuminated M kidney grille, Swarovski crystal headlights, 21" aerodynamic wheels, and Executive Theater Lounge.
- **Automotive Audio Engine**: Web Audio API integration providing subtle acoustic feedback for navigation, mode switching, and boost activation.
- **Strictly No Glassmorphism**: Designed in adherence to authentic BMW digital aesthetic—pure `#050505` black, metallic silver `#C0C0C0`, and restrained electric blue accents.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animation & Scroll**: GSAP 3.12, ScrollTrigger, Lenis
- **3D Particles**: Three.js
- **Audio**: Web Audio API Sound Synthesizer
- **Typography**: Space Grotesk, JetBrains Mono, Inter

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation
```bash
git clone https://github.com/fathimashaheed674-cmd/BMW-landing-page.git
cd BMW-landing-page
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build
```bash
npm run build
```
The optimized production bundle will be created in the `dist` folder.
